# nested-sortable

An editable data table where rows can be dragged and nested under each other. Built with jQuery UI and the [nestedSortable](https://github.com/ilikenwf/nestedSortable) plugin.

## Features

- Drag rows by the grip handle to reorder them or nest them under another row
- Expand and collapse rows that have children
- Edit a row inline (name, gender, weight, birthday, bio, status) with the gear icon and save it with the floppy icon
- Move Up / Move Down buttons, plus the same options on right click
- See the current structure with the Serialize, To array and To hierarchy buttons

## Running it

No build step. Open `index.html` in a browser.

## Stack

HTML, CSS, JavaScript, jQuery 3.6, jQuery UI, nestedSortable, Font Awesome
